ABOUT BLOCKSTREAK

Learn the dApp before connecting.

BlockWei Streaks is an experimental Ethereum application deployed on the Sepolia test network. It records a deposit position, counts the Ethereum blocks completed while that position remains active, and lets qualifying wallets claim permanent milestone achievements.

01 · CONNECT

Use MetaMask on Sepolia

Connect a wallet and switch to the Sepolia network. Sepolia ETH is test currency and has no intended monetary value.

02 · BUILD

Start a block streak

Deposit at least 0.01 test ETH. The smart contract calculates your active streak from Ethereum block numbers rather than a private website database.

03 · CLAIM

Unlock achievements

Claim milestones after reaching their required block counts. A monetary milestone reward exists only when the owner has created and funded a campaign.

What network and contract does BlockWei use?

This build uses the Ethereum Sepolia test network and contract 0x96a7A547dF1331BdfAF139Db39AEeef2711D669e. Always verify the network and address in MetaMask before approving a transaction.

Is the base reward meaningful income?

No. The base reward is deliberately tiny: one wei per completed block per deposited ETH. Network gas will generally cost much more than the reward. This Sepolia build is a product and contract demonstration, not an investment product.

Can I withdraw my deposited test ETH?

The interface calls the contract's withdrawal function for the amount you enter. Read every MetaMask transaction carefully, confirm that the amount is correct, and test with small amounts first.

What information does this site collect?

The blockchain exposes public wallet activity by design. If the optional Google Analytics ID is configured, the site also records general usage events such as wallet connection, contract loading, confirmed actions, and streak sharing. It does not intentionally send seed phrases, private keys, wallet balances, or full wallet addresses to Analytics.

Safety and privacy notice

This interface never needs your seed phrase or private key. Wallet addresses and transactions are public on Ethereum. Optional analytics measure site usage; by using the site, visitors should review any published privacy terms applicable in their location. Smart contracts can contain bugs, transactions can fail, and testnet behavior does not prove production security. Inspect the contract on Sepolia Etherscan.
